# AI Agentic Code Review Platform

A production-ready AI-powered code review and analysis platform built to understand
real-world software development, deployment, and system integration.

🔗 Live Demo:
- Frontend: https://ai-agentic-frontend1.onrender.com
- Backend API: https://ai-agentic-backend1.onrender.com/health

---

## 🚀 What This Project Does

- AI-powered chat for developer queries
- GitHub repository analysis (architecture, code quality, improvements)
- Multi-file code analysis via upload
- Context-aware AI responses using conversation memory
- Deployed full-stack system accessible publicly

---

## 🧠 Why I Built This

The goal was **not to build a ChatGPT clone**, but to:
- Understand how real software products are designed
- Learn API integration with modern LLMs
- Handle deployment, environment variables, CORS, Docker, and cloud hosting
- Gain experience debugging production issues (model deprecation, API failures, CORS)

---

## 🛠️ Tech Stack

### Frontend
- React (Vite)
- JavaScript (ES6)
- Fetch API

### Backend
- FastAPI (Python)
- Groq LLM API (LLaMA 3.1)
- RESTful API design

### DevOps / Deployment
- Docker
- Render (cloud deployment)
- Environment variable management
- CORS configuration

---

## 📌 Key Learnings

- Designing API-first architectures
- Integrating third-party AI services safely
- Prompt engineering for feature expansion without backend changes
- Production debugging and monitoring
- Building deployable, scalable systems
